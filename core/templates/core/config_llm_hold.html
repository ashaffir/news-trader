How it works
  • Confidence Weights: Blend impact, recency, clarity, volatility, duration into a final score.
  • Hold Time: Combines time-to-peak estimates with a decay tail and minimum floor.
  • Equations:
    confidence = w1·impact + w2·(1−time_gap) + w3·clarity + w4·vol_sens + w5·duration
    time_to_peak = clamp(min,max, base + a·(1−time_gap)^exp)
    hold_time = max(min_hold, time_to_peak + tail_mult · duration^tail_exp)
